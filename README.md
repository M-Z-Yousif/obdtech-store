# OBDTech Store

Arabic, mobile-first store page for OBDTech (car diagnostic tools, Iraq).
Orders are sent to WhatsApp with cash on delivery.

- `index.html` — the whole site (products are in the `P` list inside the script)
- `images/<product-id>.jpg` — product photos, e.g. `images/usta.jpg`, `images/a30m.jpg`
- Meta Pixel: dataset 816372657655264
- Order source: add `?src=qr`, `?src=wa`, `?src=fb`, `?src=ig`, `?src=tiktok` to shared links
